# canine_skin_R_analysis

16S and ITS analysis:
1. Read drop out QC across previously conducted read-filtering and ASV denoising   
2. Run decontam to remove potential contaminants
3. Visualize diversity 
4. Longitudinal analysis using bray-curtis distances between paired control and surgical samples 
5. (16S-only) Differential abundance analysis (Wilcoxon paired signed-rank test) comparing baseline with samples from post-surgery and skin maturation stages
